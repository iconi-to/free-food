# Free food icons

120 food icons in SVG from the Mini collection of [Iconito](https://iconi.to). They share one warm, flat style and are simplified so each one still reads at 24 px.

## Use them

Each icon is a single SVG in the root of this repo, named by its id: `strawberry.svg`, `pad_thai.svg`, `fried_egg_dish.svg`.

```html
<img src="strawberry.svg" width="24" height="24" alt="Strawberry">
```

They're free for personal and commercial work under the [MIT license](LICENSE): sites, apps, games, menus, slides.

Working in Figma? The same 120 icons are on [Figma Community](https://www.figma.com/community/file/1694060106042967067) as 24×24 components, grouped by category.
